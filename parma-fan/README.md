# Шестой игрок — фан-десктоп БК «БЕТСИТИ ПАРМА»

https://parma-fan.oxion-ezhkov.workers.dev

Отдельный Cloudflare Worker (не трогает корневой `tasktracker`).

- **Матч-центр** — ближайший/идущий матч с обратным отсчётом, форма, лидеры, таблица ВТБ, табло тура.
- **Онлайн-табло** — счёт, четверти, часы, график динамики, ход матча и бокс-скор; обновление каждые 10 с.
  Любой прошедший матч открывается как протокол.
- **Календарь** — сетка месяца по всем турнирам, экспорт в .ics (весь сезон или один матч).
- **Турниры** — таблицы и плей-офф текущего сезона + история по сезонам с 2009/10, график мест в Единой лиге ВТБ.
- **Команда** — карточки игроков (статистика, броски), тренерский штаб.
- **Арена и карта** — УДС «Молот», карта выездов с расстояниями, FAQ болельщика.
- **Пармыч** — ИИ-помощник на Workers AI; в контекст подставляются живые данные (состав, матчи, таблицы, счёт).

Данные: публичный API Infobasket (`org.infobasket.su`) — тот же протокол, что у vtb-league.com и parmabasket.ru.

## Деплой

```
cd parma-fan
npx wrangler deploy
```

UI (`public/`) встраивается в скрипт как текстовые модули (`app.txt` отдаётся как `/app.js`).
