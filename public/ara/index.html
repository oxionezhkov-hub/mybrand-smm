1 Big picture: performance, productivity, efficiency Общая картина: результативность, производительность, эффективность

Performance measurement is quantifying how well a unit turns resources into results (Neely: “the process of quantifying the efficiency and effectiveness of action”).

Productivity is a ratio: output / input. With one input it is a partial productivity (e.g. energy per tonne of fuel); with all inputs combined it is total factor productivity (TFP).

Efficiency compares a unit with the best possible result, not with the average. The best possible results form the frontier: maximum output for given inputs, or minimum inputs for given output. A unit on the frontier is efficient (score 1); a unit inside it is inefficient (score < 1).

The units being compared are called DMUs (decision-making units): firms, hospitals, heat & power stations.

Frontier analysis builds the frontier from data and measures each DMU's distance to it. Two families:

  • Parametric (econometrics): assume a formula for the frontier, e.g. Cobb–Douglas. Methods: DPF, SFA.
  • Non-parametric (linear programming): no formula, the frontier is built from the best observed DMUs. Methods: DEA (CCR, BCC), FDH.

Benchmarking = comparing with best practice to find how much and where to improve. Frontier methods are formal benchmarking.

Измерение результативности — количественная оценка того, насколько хорошо единица превращает ресурсы в результат (Нили: «процесс количественной оценки эффективности и результативности действий»).

Производительность — отношение выпуска к затратам. По одному ресурсу это частная производительность (энергия на тонну топлива), по всем сразу — совокупная факторная производительность (TFP).

Эффективность сравнивает единицу с лучшим возможным результатом, а не со средним. Лучшие возможные результаты образуют границу (frontier): максимум выпуска при данных затратах или минимум затрат при данном выпуске. Единица на границе эффективна (оценка 1), внутри — неэффективна (оценка < 1).

Сравниваемые единицы называют DMU (decision-making units): фирмы, больницы, ТЭЦ.

Граничный анализ строит границу по данным и измеряет расстояние до неё. Два семейства:

  • Параметрические (эконометрика): границу задают формулой, например Кобба–Дугласа. Методы: DPF, SFA.
  • Непараметрические (линейное программирование): формулы нет, граница строится по лучшим наблюдаемым DMU. Методы: DEA (CCR, BCC), FDH.

Бенчмаркинг — сравнение с лучшей практикой, чтобы понять, где и насколько улучшаться. Граничные методы — формализованный бенчмаркинг.

На экзамене: напрямую не спрашивают, но без этой рамки не понять остальные темы. В выводах всегда пишите, что оценка — расстояние до границы лучшей практики.

2 Production technology Технология производства

Inputs x = (x₁,…,xₙ), outputs y = (y₁,…,yₘ). A production plan is a pair (x, y).

The technology set (graph) T = {(x, y): x can produce y} is the set of all feasible plans. Two views of the same set:

  • Input set L(y): all input bundles that can produce y.
  • Output set P(x): all output bundles that x can produce.

Their boundaries are isoquants. The input isoquant Isoq L(y) contains bundles that cannot be shrunk radially and still produce y.

Technical efficiency (Pareto–Koopmans): a plan is efficient if you cannot increase any output or decrease any input without worsening something else.

Assumptions about T decide which DEA model you get:

  • Free disposability: more input can always produce at least the same output (you can waste). Gives FDH.
  • + Convexity: mixtures of feasible plans are feasible. Gives BCC (VRS).
  • + Constant returns to scale: if (x, y) is feasible, so is (kx, ky). Gives CCR (CRS).

Built from n observed DMUs with input matrix X and output matrix Y:

Ресурсы x = (x₁,…,xₙ), продукты y = (y₁,…,yₘ). Производственный план — пара (x, y).

Технологическое множество (граф) T = {(x, y): из x можно произвести y} — все допустимые планы. Два взгляда на него:

  • Множество затрат L(y): все наборы ресурсов, из которых можно получить y.
  • Множество выпусков P(x): все наборы продуктов, которые можно получить из x.

Их границы — изокванты. Входная изокванта Isoq L(y) — наборы, которые нельзя пропорционально уменьшить, сохранив выпуск y.

Техническая эффективность по Парето–Купмансу: план эффективен, если нельзя увеличить ни один выпуск или уменьшить ни один ресурс, не ухудшив чего-то другого.

Предпосылки о T определяют модель DEA:

  • Свободное распоряжение (free disposability): из большего ресурса можно получить не меньше. Даёт FDH.
  • + Выпуклость: смесь допустимых планов допустима. Даёт BCC (переменная отдача, VRS).
  • + Постоянная отдача: если (x, y) допустим, то и (kx, ky). Даёт CCR (CRS).

По n наблюдаемым DMU с матрицей ресурсов X и выпусков Y:

T_CCR = {(x, y): Xλ ≤ x, Yλ ≥ y, λ ≥ 0} T_BCC = T_CCR ∩ {Σλⱼ = 1} T_FDH = T_BCC ∩ {λⱼ ∈ {0, 1}} ⇒ T_FDH ⊆ T_BCC ⊆ T_CCR

На экзамене (часть 1, задание i): «write down the technological set T for firm #5». Пишете систему: для каждого ресурса Σλⱼxᵢⱼ ≤ xᵢ,₅, для каждого продукта Σλⱼyᵣⱼ ≥ yᵣ,₅, λ ≥ 0. Готовый текст даёт вкладка 01.

3 Production function and returns to scale Производственная функция и отдача от масштаба

With one output, the frontier is a production function y = f(x): the maximum output from inputs x.

  • Average product AP₁ = f(x)/x₁; marginal product MP₁ = ∂f/∂x₁.
  • Output elasticity eᵢ = ∂ln y / ∂ln xᵢ: % change in y when xᵢ rises by 1%.
  • MRTS = MP₁/MP₂ = slope of the isoquant (how much x₂ replaces one unit of x₁).

Returns to scale: multiply all inputs by k > 1. If output rises exactly k times — constant (CRS); less — decreasing (DRS); more — increasing (IRS). Scale elasticity = Σ eᵢ.

Functional forms used in the course:

  • Linear y = a₁x₁ + a₂x₂: perfect substitutes, straight-line isoquant, CRS.
  • Leontief y = min(x₁/a, x₂/b): fixed proportions, L-shaped isoquant.
  • Cobb–Douglas y = A·x₁^α·x₂^β. In logs: ln y = ln A + α ln x₁ + β ln x₂. α, β are elasticities; α + β = 1 CRS, < 1 DRS, > 1 IRS.
  • Translog: Cobb–Douglas plus ½(ln x₁)², ½(ln x₂)² and ln x₁·ln x₂ terms. More flexible.

При одном продукте граница — производственная функция y = f(x): максимальный выпуск из ресурсов x.

  • Средний продукт AP₁ = f(x)/x₁; предельный MP₁ = ∂f/∂x₁.
  • Эластичность выпуска eᵢ = ∂ln y / ∂ln xᵢ: на сколько % вырастет y при росте xᵢ на 1%.
  • MRTS = MP₁/MP₂ — наклон изокванты (сколько x₂ заменяет единицу x₁).

Отдача от масштаба: умножаем все ресурсы на k > 1. Выпуск вырос ровно в k раз — постоянная (CRS); меньше — убывающая (DRS); больше — возрастающая (IRS). Эластичность масштаба = Σ eᵢ.

Формы в курсе:

  • Линейная y = a₁x₁ + a₂x₂: совершенные заменители, изокванта — прямая, CRS.
  • Леонтьева y = min(x₁/a, x₂/b): фиксированные пропорции, изокванта-угол.
  • Кобба–Дугласа y = A·x₁^α·x₂^β. В логарифмах: ln y = ln A + α ln x₁ + β ln x₂. α, β — эластичности; α + β = 1 — CRS, < 1 — DRS, > 1 — IRS.
  • Транслог: Кобб–Дуглас плюс ½(ln x₁)², ½(ln x₂)² и ln x₁·ln x₂. Гибче.

На экзамене (часть 3): после OLS пишут «0,153 + 0,543 = 0,696 < 1 ⇒ decreasing returns to scale». Коэффициенты ln–ln модели называйте elasticities.

4 Farrell efficiency: TE, AE, OE Эффективность по Фарреллу

Farrell (1957) splits overall inefficiency into a technical and a price part. Setting: CRS frontier, two inputs, known input prices w₁, w₂.

  • B — the actual plan.
  • B′ — where the ray OB crosses the isoquant: same input mix, no waste.
  • S — the cost-minimising point on the isoquant (isocost tangent to it, or a corner for a linear frontier).
  • F — where the ray OB crosses the minimal isocost line.
TE = OB′/OB = C(B′)/C(B) technical: wasted inputs AE = OF/OB′ = C(S)/C(B′) allocative: wrong input mix for these prices OE = OF/OB = C(S)/C(B) = TE × AE

Points on one ray differ only by scale, so distance ratios equal cost ratios: that is why the exam answer uses costs.

Algorithm: 1) f(x_actual) > y? then inefficient. 2) B′: scale x by θ so f(θx) = y; TE = θ. 3) S: cost minimum for y (linear: use only the input with the lower wᵢ/aᵢ; Cobb–Douglas: x₂/x₁ = βw₁/(αw₂)). 4) C(S), then AE = C(S)/C(B′), OE = C(S)/C(B). 5) Check TE·AE = OE.

Фаррелл (1957) делит общую неэффективность на техническую и ценовую. Условия: граница с постоянной отдачей, два ресурса, известны цены w₁, w₂.

  • B — фактический план.
  • B′ — пересечение луча OB с изоквантой: та же структура ресурсов, без перерасхода.
  • S — точка минимума издержек на изокванте (касание изокосты; у линейной границы — угол).
  • F — пересечение луча OB с минимальной изокостой.
TE = OB′/OB = C(B′)/C(B) техническая: лишние ресурсы AE = OF/OB′ = C(S)/C(B′) аллокативная: неверная структура при этих ценах OE = OF/OB = C(S)/C(B) = TE × AE

Точки на одном луче отличаются только масштабом, поэтому отношения отрезков равны отношениям издержек — так и считают в ответе.

Алгоритм: 1) f(x_факт) > y? Значит неэффективен. 2) B′: сжать x в θ раз, чтобы f(θx) = y; TE = θ. 3) S: минимум издержек для y (линейная — только ресурс с меньшим wᵢ/aᵢ; Кобб–Дуглас — x₂/x₁ = βw₁/(αw₂)). 4) C(S), затем AE = C(S)/C(B′), OE = C(S)/C(B). 5) Проверка TE·AE = OE.

На экзамене (часть 2, 2026): y = 3x₁ + 5x₂, x = (30; 15), y = 110, цены 7,5 и 15. Ответ: TE = 0,667, AE = 0,917, OE = 0,611. Калькулятор и готовый текст — во вкладке 02.

5 Distance functions Функции расстояния

Shephard's distance functions describe a multi-input, multi-output technology without prices and measure efficiency directly.

Input: Dᵢ(y, x) = max{λ: x/λ ∈ L(y)} ≥ 1, TE_input = 1/Dᵢ Output: Dₒ(x, y) = min{μ: y/μ ∈ P(x)} ≤ 1, TE_output = Dₒ

Dᵢ = 1.25 means inputs can be divided by 1.25 (cut by 20%) and still produce y: TE = 0.8. A DMU on the isoquant has Dᵢ = 1.

Properties of Dᵢ: decreasing in y, increasing in x, homogeneous of degree 1 in x, concave in x. Under CRS Dᵢ = 1/Dₒ.

DEA computes exactly these: input-oriented θ* = 1/Dᵢ, output-oriented η* = 1/Dₒ.

Функции расстояния Шепарда описывают технологию со многими ресурсами и продуктами без цен и сразу измеряют эффективность.

Входная: Dᵢ(y, x) = max{λ: x/λ ∈ L(y)} ≥ 1, TE_вход = 1/Dᵢ Выходная: Dₒ(x, y) = min{μ: y/μ ∈ P(x)} ≤ 1, TE_выход = Dₒ

Dᵢ = 1,25 значит: ресурсы можно разделить на 1,25 (сократить на 20%) и всё равно получить y, TE = 0,8. На изокванте Dᵢ = 1.

Свойства Dᵢ: убывает по y, растёт по x, однородна степени 1 по x, вогнута по x. При CRS Dᵢ = 1/Dₒ.

DEA считает именно их: входная θ* = 1/Dᵢ, выходная η* = 1/Dₒ.

На экзамене: как теоретический вопрос или тест в Blackboard: определение, связь с TE, свойства.

6 Cost function, economies of scale and scope Функция издержек, экономия от масштаба и разнообразия

C(w, y) = min {w·x : x ∈ L(y)} — the minimum cost of producing y at input prices w.

Properties: non-decreasing in w and y, homogeneous of degree 1 in w (double all prices → cost doubles), concave in w. Shephard's lemma: xᵢ* = ∂C/∂wᵢ.

For C = g(w)·h(y) with g = ∏wᵢ^aᵢ, homogeneity requires Σaᵢ = 1.

Economies of scale: average cost falls as output grows.

Economies of scope: producing together is cheaper than separately:

C(q₁, q₂) < C(q₁, 0) + C(0, q₂) SC = [C(q₁,0) + C(0,q₂) − C(q₁,q₂)] / C(q₁,q₂) > 0 Cost complementarity: ∂²C/∂q₁∂q₂ < 0 ⇒ economies of scope

If two products sit in separate additive terms of C, their cross derivative is 0: no cost complementarity between them.

C(w, y) = min {w·x : x ∈ L(y)} — минимальные издержки выпуска y при ценах ресурсов w.

Свойства: не убывает по w и y, однородна степени 1 по w (цены удвоились — издержки удвоились), вогнута по w. Лемма Шепарда: xᵢ* = ∂C/∂wᵢ.

Для C = g(w)·h(y) с g = ∏wᵢ^aᵢ однородность требует Σaᵢ = 1.

Экономия от масштаба: средние издержки падают с ростом выпуска.

Экономия от разнообразия (scope): вместе производить дешевле, чем по отдельности:

C(q₁, q₂) < C(q₁, 0) + C(0, q₂) SC = [C(q₁,0) + C(0,q₂) − C(q₁,q₂)] / C(q₁,q₂) > 0 Комплементарность издержек: ∂²C/∂q₁∂q₂ < 0 ⇒ экономия от разнообразия

Если два продукта стоят в разных слагаемых C, смешанная производная равна 0: комплементарности между ними нет.

7 Average production function (OLS) Средняя производственная функция (МНК)

Regress ln y on ln x₁, ln x₂ by OLS: ln y = β₀ + β₁ ln x₁ + β₂ ln x₂ + ε.

OLS fits through the middle of the data: it describes the average station, not best practice. ε > 0 means better than average.

How to read the output:

  • Coefficients β₁, β₂: elasticities (see topic 3).
  • t-statistic / p-value: is the coefficient different from 0? p < 0.05 → significant at 5%.
  • R²: share of variation in ln y explained (0.36 = 36%).
  • F-test: are all slopes jointly zero? Small p → the model as a whole is significant.

A = e^β₀ gives the multiplicative form y = A·x₁^β₁·x₂^β₂.

Регрессия ln y на ln x₁, ln x₂ методом МНК: ln y = β₀ + β₁ ln x₁ + β₂ ln x₂ + ε.

МНК проводит линию через середину данных: описывает среднюю станцию, а не лучшую практику. ε > 0 — лучше среднего.

Как читать вывод:

  • Коэффициенты β₁, β₂: эластичности (тема 3).
  • t-статистика / p-value: отличается ли коэффициент от 0? p < 0,05 — значим на 5%.
  • R²: доля объяснённой вариации ln y (0,36 = 36%).
  • F-тест: все ли наклоны одновременно нули? Малое p — модель в целом значима.

A = e^β₀ даёт мультипликативную форму y = A·x₁^β₁·x₂^β₂.

Stata: regress lny lnx1 lnx2 Excel: Данные → Анализ данных → Регрессия (Y = ln y, X = ln x1, ln x2)

На экзамене (часть 3): «estimate the average production function and provide statistical characteristics»: уравнение, t, p, R², F, вывод об отдаче.

8 Deterministic production frontier (COLS) Детерминированная граница (COLS)

Model: ln yᵢ = f(xᵢ; β) − uᵢ, uᵢ ≥ 0. All deviation from the frontier is treated as inefficiency; there is no noise.

Corrected OLS (COLS): keep the OLS slopes, shift the intercept up by the largest residual:

β₀^DPF = β₀^OLS + max eᵢ uᵢ = max e − eᵢ ≥ 0 TEᵢ = exp(−uᵢ) = yᵢ / yᵢ* (output-oriented)

Exactly one DMU (the one with the largest residual) ends up on the frontier with TE = 1.

Weaknesses: one outlier defines the whole frontier; luck and measurement errors are counted as inefficiency, so TE comes out low (in the 2026 variant mean TE = 0.26).

MOLS (modified OLS) shifts by the expected E[u] under an assumed distribution instead of the maximum.

Модель: ln yᵢ = f(xᵢ; β) − uᵢ, uᵢ ≥ 0. Всё отклонение от границы считается неэффективностью, шума нет.

Скорректированный МНК (COLS): наклоны из МНК сохраняем, константу поднимаем на максимальный остаток:

β₀^DPF = β₀^OLS + max eᵢ uᵢ = max e − eᵢ ≥ 0 TEᵢ = exp(−uᵢ) = yᵢ / yᵢ* (выходная ориентация)

На границе оказывается ровно одна DMU — с наибольшим остатком, TE = 1.

Недостатки: один выброс задаёт всю границу; удача и ошибки измерения записываются в неэффективность, поэтому TE занижена (в варианте 2026 средняя 0,26).

MOLS сдвигает не на максимум, а на ожидаемое E[u] при выбранном распределении.

На экзамене (часть 3): «construct the DPF, write its equation, calculate TE for every station, min/mean/max». Do-файл во вкладке 03 делает это тремя строками.

9 Stochastic frontier analysis (SFA) Стохастическая граница (SFA)

Aigner, Lovell & Schmidt (1977); Meeusen & van den Broeck (1977). The error has two parts:

ln yᵢ = xᵢ′β + vᵢ − uᵢ vᵢ ~ N(0, σᵥ²) noise: weather, luck, measurement error (symmetric) uᵢ ≥ 0 inefficiency (one-sided) cost frontier: ln Cᵢ = … + vᵢ + uᵢ

Distribution of u (the four models in the exam): half-normal N⁺(0, σᵤ²); exponential; truncated normal N⁺(μ, σᵤ²); gamma. Estimated by maximum likelihood (ML).

Key parameters: λ = σᵤ/σᵥ; σ² = σᵤ² + σᵥ²; γ = σᵤ²/σ² (share of inefficiency in total variance: γ → 0 means no inefficiency, OLS is enough; γ → 1 means almost deterministic frontier).

Is there inefficiency at all?

  • Skewness of OLS residuals must be negative (v − u leans left). Positive = “wrong skewness”: ML sets σᵤ = 0 and SFA = OLS.
  • LR test H₀: σᵤ = 0. LR = 2(lnL_SFA − lnL_OLS). Critical value at 5% is 2.706 (mixed χ²: ½χ²(0) + ½χ²(1)). LR > 2.706 → inefficiency is significant.

Unit TE. u is not observed, only ε. We predict it from ε:

  • JLMS: E[u|ε], TE = exp(−E[u|ε]) — Stata jlms.
  • Battese–Coelli: TE = E[exp(−u)|ε] — Stata bc (not for gamma).

TE = 0.7: the station produces 70% of what is possible with its inputs; it could raise output by 1/0.7 − 1 = 43%.

Comparing models: lnL / AIC, significance of σᵤ and λ, convergence (gamma often fails), Spearman rank correlation of TE.

Айгнер, Ловелл и Шмидт (1977); Мёзен и ван ден Брук (1977). Ошибка состоит из двух частей:

ln yᵢ = xᵢ′β + vᵢ − uᵢ vᵢ ~ N(0, σᵥ²) шум: погода, удача, ошибки измерения (симметричный) uᵢ ≥ 0 неэффективность (односторонняя) граница издержек: ln Cᵢ = … + vᵢ + uᵢ

Распределение u (четыре модели в экзамене): полунормальное N⁺(0, σᵤ²); экспоненциальное; усечённое нормальное N⁺(μ, σᵤ²); гамма. Оценка — метод максимального правдоподобия (ML).

Ключевые параметры: λ = σᵤ/σᵥ; σ² = σᵤ² + σᵥ²; γ = σᵤ²/σ² (доля неэффективности в общей дисперсии: γ → 0 — неэффективности нет, хватает МНК; γ → 1 — почти детерминированная граница).

Есть ли неэффективность вообще?

  • Асимметрия остатков МНК должна быть отрицательной (v − u скошено влево). Положительная — «wrong skewness»: ML даёт σᵤ = 0 и SFA = OLS.
  • LR-тест H₀: σᵤ = 0. LR = 2(lnL_SFA − lnL_OLS). Критическое значение на 5% — 2,706 (смесь ½χ²(0) + ½χ²(1)). LR > 2,706 — неэффективность значима.

TE отдельной единицы. u не наблюдается, только ε. Прогнозируем по ε:

  • JLMS: E[u|ε], TE = exp(−E[u|ε]) — в Stata jlms.
  • Battese–Coelli: TE = E[exp(−u)|ε] — в Stata bc (кроме gamma).

TE = 0,7: станция выпускает 70% возможного при своих ресурсах; может нарастить выпуск на 1/0,7 − 1 = 43%.

Сравнение моделей: lnL / AIC, значимость σᵤ и λ, сходимость (gamma часто не сходится), ранговая корреляция Спирмена между TE.

10 DEA: the idea and the CCR model DEA: идея и модель CCR

Data Envelopment Analysis (Charnes, Cooper, Rhodes, 1978) builds the frontier as an envelope of the best DMUs by linear programming. No formula, no noise.

Ratio idea (multiplier form): efficiency = Σuᵣyᵣ / Σvᵢxᵢ (virtual output / virtual input). Each DMU picks the weights u, v most favourable to itself, subject to no DMU scoring above 1.

Envelopment form (what DEA-Solver solves): find a combination of DMUs (weights λⱼ) that uses at most θ times my inputs and produces at least my outputs; make θ as small as possible.

CCR-I (input-oriented, DMU o): min θ s.t. Σⱼ λⱼ xᵢⱼ ≤ θ·xᵢₒ for every input i Σⱼ λⱼ yᵣⱼ ≥ yᵣₒ for every output r λⱼ ≥ 0 CCR-O (output-oriented): max η s.t. Σⱼ λⱼ xᵢⱼ ≤ xᵢₒ Σⱼ λⱼ yᵣⱼ ≥ η·yᵣₒ λⱼ ≥ 0 score = 1/η*

θ* = 1: nobody does better, the DMU is on the frontier. θ* = 0.8: the same outputs could be made with 80% of the inputs.

Under CRS input and output orientation give the same score (θ* = 1/η*).

Limits: deterministic (noise = inefficiency), sensitive to outliers, needs enough DMUs: n ≥ max{m·s, 3(m+s)}.

Анализ среды функционирования (DEA; Чарнс, Купер, Роудс, 1978) строит границу как оболочку лучших DMU методом линейного программирования. Формулы нет, шума нет.

Идея отношения (мультипликативная форма): эффективность = Σuᵣyᵣ / Σvᵢxᵢ (взвешенный выпуск / взвешенные затраты). Каждая DMU выбирает самые выгодные для себя веса u, v при условии, что ни одна DMU не получит больше 1.

Огибающая форма (её решает DEA-Solver): найти комбинацию DMU (веса λⱼ), которая тратит не больше θ моих ресурсов и выпускает не меньше моего; сделать θ минимальным.

CCR-I (входная ориентация, DMU o): min θ при Σⱼ λⱼ xᵢⱼ ≤ θ·xᵢₒ для каждого ресурса i Σⱼ λⱼ yᵣⱼ ≥ yᵣₒ для каждого продукта r λⱼ ≥ 0 CCR-O (выходная ориентация): max η при Σⱼ λⱼ xᵢⱼ ≤ xᵢₒ Σⱼ λⱼ yᵣⱼ ≥ η·yᵣₒ λⱼ ≥ 0 оценка = 1/η*

θ* = 1: никто не делает лучше, DMU на границе. θ* = 0,8: тот же выпуск можно получить из 80% ресурсов.

При CRS входная и выходная ориентации дают одну оценку (θ* = 1/η*).

Ограничения: детерминированность (шум = неэффективность), чувствительность к выбросам, нужно достаточно DMU: n ≥ max{m·s, 3(m+s)}.

На экзамене (часть 1): записать CCR-O для фирмы №5 с числами из таблицы. Это ровно форма выше: подставьте столбец каждой фирмы как коэффициенты при λⱼ.

11 BCC, FDH and scale efficiency BCC, FDH и эффективность масштаба

BCC (Banker, Charnes, Cooper, 1984) adds Σλⱼ = 1: variable returns to scale. A DMU is compared only with convex mixtures of DMUs of similar size; the frontier hugs the data tighter.

FDH (Deprins, Simar, Tulkens, 1984) = BCC with λⱼ ∈ {0,1}: exactly one λ = 1, so a DMU is compared only with real observed DMUs that dominate it (use no more of every input and produce no less of every output). Staircase frontier. It is a mixed-integer problem, solved by simple enumeration of dominating units.

Why FDH comes from BCC, not CCR: FDH keeps Σλ = 1 and only replaces λ ≥ 0 with λ ∈ {0,1}; CCR has no Σλ = 1 to keep.

Nesting T_FDH ⊆ T_BCC ⊆ T_CCR gives:

θ_FDH ≥ θ_BCC ≥ θ_CCR (for every DMU) #efficient: FDH ≥ BCC ≥ CCR Scale efficiency: SE = θ_CCR / θ_BCC ≤ 1 θ_CCR = θ_BCC (pure technical) × SE

Returns to scale of a DMU: from Σλⱼ* in CCR — < 1 increasing, = 1 constant, > 1 decreasing.

BCC-I and BCC-O find the same set of efficient DMUs but different scores for inefficient ones.

BCC (Банкер, Чарнс, Купер, 1984) добавляет Σλⱼ = 1: переменная отдача от масштаба. DMU сравнивается только со смесями DMU похожего размера, граница плотнее облегает данные.

FDH (Депринс, Симар, Тюлкенс, 1984) = BCC с λⱼ ∈ {0,1}: ровно одна λ = 1, DMU сравнивается только с реальными DMU, которые её доминируют (каждого ресурса не больше, каждого продукта не меньше). Граница-лесенка. Задача смешанного целочисленного программирования, решается перебором доминирующих.

Почему FDH из BCC, а не из CCR: FDH сохраняет Σλ = 1 и лишь заменяет λ ≥ 0 на λ ∈ {0,1}; в CCR условия Σλ = 1 нет.

Вложенность T_FDH ⊆ T_BCC ⊆ T_CCR даёт:

θ_FDH ≥ θ_BCC ≥ θ_CCR (для каждой DMU) число эффективных: FDH ≥ BCC ≥ CCR Эффективность масштаба: SE = θ_CCR / θ_BCC ≤ 1 θ_CCR = θ_BCC (чисто техническая) × SE

Отдача от масштаба DMU — по Σλⱼ* в CCR: < 1 возрастающая, = 1 постоянная, > 1 убывающая.

BCC-I и BCC-O находят одно и то же множество эффективных DMU, но разные оценки у неэффективных.

12 Slacks, reference sets, frontier equations, projections Слэки, эталоны, уравнения границы, проекции

After the radial cut by θ some inputs may still be reducible, or some outputs still increasable: these leftovers are slacks (s⁻ for inputs, s⁺ for outputs). They appear where the frontier runs parallel to an axis.

DEA-Solver works in two phases: first the smallest θ, then the largest slacks with θ fixed.

  • Efficient (Pareto–Koopmans): θ* = 1 and all slacks = 0.
  • Weakly efficient: θ* = 1 but some slack > 0.

Reference set (peers) of DMU o: the efficient DMUs with λⱼ* > 0. They are its benchmarks. DMUs that appear in many reference sets are robust best practice.

Frontier equations (course style) say that the target point is a λ-combination of the peers:

input i: θ*·xᵢₒ − sᵢ⁻ = Σⱼ λⱼ* xᵢⱼ output r: yᵣₒ + sᵣ⁺ = Σⱼ λⱼ* yᵣⱼ e.g. 0.7506 × 617 638 = 0.436 × 421 206 + 0.311 × 422 930 + 0.264 × 561 864

Projection (target) = the point on the frontier:

input orientation: x̂ = θ*x − s⁻, ŷ = y + s⁺ output orientation: x̂ = x − s⁻, ŷ = η*y + s⁺ change % = (projection − data) / data × 100

For FDH the projection is simply the data of the one dominating DMU.

Interpretation template: “DMU 39 can cut gas and oil by 25% (to 463 569 and 26 287) with no loss of electricity and heat, following the practice of DMUs 4, 6 and 35.”

После радиального сжатия на θ какие-то ресурсы ещё можно уменьшить, а продукты — увеличить: эти остатки — слэки (s⁻ по ресурсам, s⁺ по продуктам). Они возникают там, где граница идёт параллельно оси.

DEA-Solver работает в две фазы: сначала минимальное θ, затем максимальные слэки при этом θ.

  • Эффективна (по Парето–Купмансу): θ* = 1 и все слэки = 0.
  • Слабо эффективна: θ* = 1, но есть слэк > 0.

Reference set (эталоны) DMU o — эффективные DMU с λⱼ* > 0. Это её образцы. DMU, которые встречаются в reference sets многих, — устойчивая лучшая практика.

Уравнения границы (как в курсе) показывают, что целевая точка — λ-комбинация эталонов:

ресурс i: θ*·xᵢₒ − sᵢ⁻ = Σⱼ λⱼ* xᵢⱼ продукт r: yᵣₒ + sᵣ⁺ = Σⱼ λⱼ* yᵣⱼ напр. 0,7506 × 617 638 = 0,436 × 421 206 + 0,311 × 422 930 + 0,264 × 561 864

Проекция (цель) — точка на границе:

входная ориентация: x̂ = θ*x − s⁻, ŷ = y + s⁺ выходная ориентация: x̂ = x − s⁻, ŷ = η*y + s⁺ изменение % = (проекция − факт) / факт × 100

У FDH проекция — просто данные одной доминирующей DMU.

Шаблон интерпретации: «DMU 39 может сократить газ и мазут на 25% (до 463 569 и 26 287) без потери электроэнергии и тепла, ориентируясь на DMU 4, 6 и 35».

  • Rank: DMUs sorted by score; all efficient ones share rank 1.
  • Weight: multiplier weights v (inputs), u (outputs), u₀ for BCC.
  • Slack: s⁻ and s⁺ per DMU.
  • Projection: Data, Projection, Difference, % for each input and output. Copy these rows into the projections table.
  • Summary: модель, число DMU, средняя/максимальная/минимальная оценка, число эффективных.
  • Score: оценка θ* (или 1/η* у выходных моделей), ранг, reference set с λ. Главный лист.
  • Rank: DMU по убыванию оценки; все эффективные делят ранг 1.
  • Weight: веса v (ресурсы), u (продукты), u₀ у BCC.
  • Slack: s⁻ и s⁺ по каждой DMU.
  • Projection: Data, Projection, Difference, % по каждому ресурсу и продукту. Эти строки переносите в таблицу проекций.

15 Performance measurement frameworks Системы измерения результативности

From lecture 1 and the readings; useful for theory questions and quizzes.

  • Benchmarking stages (lecture 1, 9 steps): object → goal → KPIs (data selection) → sample of units → data collection → construct the best-practice benchmark → compare each unit with it → analyse relative positions and improvement opportunities → learning (benchlearning).
  • KPIs are simple ratios; frontier methods combine many inputs and outputs into one score.
  • Performance Prism (Neely & Adams): five facets — stakeholder satisfaction, strategies, processes, capabilities, stakeholder contribution.
  • 7 deadly sins (Hammer, MIT SMR 2007): vanity, provincialism, narcissism, laziness, pettiness, inanity, frivolity — measuring what flatters or is easy instead of what drives results.
  • Pidd (2010): models are simplifications to support decisions; their value is in use, not in precision.

Из лекции 1 и литературы; пригодится для теоретических вопросов и тестов.

  • Этапы бенчмаркинга (лекция 1, 9 шагов): объект → цель → KPI (выбор данных) → выборка единиц → сбор данных → построение эталона лучшей практики → сравнение каждой единицы с ним → анализ позиций и возможностей улучшения → обучение (benchlearning).
  • KPI — простые отношения; граничные методы сводят много ресурсов и продуктов в одну оценку.
  • Performance Prism (Нили и Адамс): пять граней — удовлетворённость стейкхолдеров, стратегии, процессы, возможности, вклад стейкхолдеров.
  • 7 смертных грехов (Хаммер, MIT SMR 2007): тщеславие, провинциализм, нарциссизм, лень, мелочность, бессмысленность, легкомыслие — мерить то, что льстит или удобно, а не то, что движет результатом.
  • Пидд (2010): модель — упрощение для поддержки решений; её ценность в использовании, а не в точности.

Технологическое множество

T_CCR = {(x,y): Xλ ≤ x, Yλ ≥ y, λ ≥ 0} T_BCC = T_CCR + eλ = 1 T_FDH = T_BCC + λⱼ ∈ {0,1}

Вложенность T_FDH ⊆ T_BCC ⊆ T_CCR даёт θ_FDH ≥ θ_BCC ≥ θ_CCR и обратный порядок по числу эффективных DMU.

Ориентация

Input: min θ, Xλ ≤ θxo, Yλ ≥ yo. Оценка θ* ≤ 1.

Output: max η, Xλ ≤ xo, Yλ ≥ ηyo. η* ≥ 1, оценка эффективности 1/η*.

При CRS θ* = 1/η*, при VRS значения могут различаться, но множество эффективных DMU одно и то же.

Можно ли записать FDH?

Да. FDH получается из BCC: условие выпуклости Σλ = 1 сохраняется, а λⱼ ≥ 0 заменяется на λⱼ ∈ {0,1}. Ровно одна λ равна 1, эталоном служит реально наблюдаемая фирма. Это задача смешанного целочисленного программирования. Из CCR FDH не получить: там нет Σλ = 1.

Определения, которые проверяют

TE = OB′/OB = C(B′)/C(B) (Farrell, input-oriented) AE = OF/OB′ = C(S)/C(B′) OE = OF/OB = C(S)/C(B) = TE × AE
  • План технически неэффективен, если f(x) > y: из тех же ресурсов можно выпустить больше.
  • Линейная граница (совершенные субституты): минимум издержек в углу, сравниваем w₁/a₁ и w₂/a₂.
  • Cobb–Douglas: MRTS = (α·x₂)/(β·x₁) = w₁/w₂ ⇒ x₂/x₁ = β·w₁/(α·w₂).
  • Леонтьев: AE = 1 только если факт на луче вершины; оптимум x₁ = a·y, x₂ = b·y.

Distance functions и отдача от масштаба

Dᵢ(y,x) = max{λ: x/λ ∈ L(y)} ≥ 1, TE_input = 1/Dᵢ Dₒ(x,y) = min{μ: y/μ ∈ P(x)} ≤ 1, TE_output = Dₒ CRS: Dᵢ = 1/Dₒ
  • Dᵢ убывает по y, растёт по x, однородна степени 1 по x, вогнута по x. Isoq L(y) = {x: Dᵢ = 1}.
  • Cobb–Douglas y = A∏xᵢ^αᵢ: Σαᵢ = 1 — CRS, > 1 — IRS, < 1 — DRS. Коэффициенты ln–ln модели — эластичности выпуска.
  • Пример 2026: 0,153 + 0,543 = 0,696 < 1 ⇒ убывающая отдача.

Economies of scope (вариант 2020)

SC = [C(q₁,0) + C(0,q₂) − C(q₁,q₂)] / C(q₁,q₂) SC > 0 — economies of scope, SC < 0 — diseconomies Cost complementarity: ∂²C/∂qᵢ∂qⱼ < 0 ⇒ economies of scope
  1. Проверьте, что C однородна степени 1 по ценам: сумма степеней wᵢ должна быть 1. В задаче 2020: 0,3 + 0,5 + 0,8 + 0,2 = 1,8, это нарушение свойства функции издержек, его стоит отметить.
  2. Для каждой пары продуктов посчитайте ∂²C/∂qᵢ∂qⱼ. Слагаемые, которые не содержат обоих qᵢ и qⱼ, дают ноль: такая пара не связана в издержках.
  3. Если продукт стоит с отрицательной степенью (q³⁻⁰·¹), C(…, qⱼ = 0, …) не определена или бесконечна: выпускать его партнёра отдельно невозможно, совместное производство обязательно.
  4. Аддитивно разделимые группы продуктов (C = g(w)·[h₁(q₁,q₃) + h₂(q₂)]) дают нулевую комплементарность между группами: экономии от разнообразия между ними нет, если нет общих постоянных издержек.

Average PF → DPF → SFA

Вставьте выборку (в экзамене она уже в натуральных логарифмах), выберите столбцы. Страница считает OLS, COLS-границу и три SFA-модели методом максимального правдоподобия, чтобы сверить ваш вывод Stata.

Gamma в браузере не считается: в Stata она оценивается симулированным правдоподобием и часто не сходится. Остальные модели совпадают с Stata до 2–3 знака; у tnormal μ определяется слабо, расхождение может быть больше.

Do-файл для Stata

Имена переменных берутся из заголовков выше. Данные вставьте в Data Editor (Ctrl+V с первой строкой как именами).

Что писать в выводах

  • Average PF: коэффициенты ln–ln — эластичности, их сумма даёт отдачу от масштаба. R², F, t-статистики.
  • DPF (COLS): к константе прибавляется max OLS-остаток; TEᵢ = exp(eᵢ − max e), одна станция ровно на границе. Всё отклонение считается неэффективностью, граница держится на одном выбросе.
  • SFA: ε = v − u, v ~ N(0,σᵥ²) шум, u ≥ 0 неэффективность. λ = σᵤ/σᵥ, γ = σᵤ²/(σᵤ²+σᵥ²).
  • Проверка наличия неэффективности: асимметрия OLS-остатков должна быть отрицательной (sktest); LR = 2(lnL_SFA − lnL_OLS) против критического 2,706 (смесь ½χ²(0) + ½χ²(1), 5%).
  • TE: bc = E[exp(−u)|ε] (Battese–Coelli), jlms = exp(−E[u|ε]). Обе — выходно-ориентированные.
  • Согласованность: ранговая корреляция Спирмена между TE моделей. Уровни отличаются, ранги обычно почти совпадают.
  • Выбор модели: SFA предпочтительнее DPF по сути (шум отделён). Среди распределений — по lnL/AIC и значимости σᵤ; half-normal и exponential устойчивее, tnormal и gamma слабо идентифицируются.

Wrong skewness

Если остатки OLS имеют положительную асимметрию (для границы производства), ML-оценка σᵤ уходит в ноль и SFA совпадает с OLS (результат Waldman, 1982). В варианте 2 так и вышло: асимметрия около нуля, LR ≈ 0,01, σᵤ незначима. Правильный ответ — признать, что неэффективность статистически не выделяется, и всё равно выбрать модель с обоснованием.
